How to Alt-Tab on Mac

The Mac has no Alt-Tab. ⌘ ⇥ switches apps, not windows. Tern uses ⌥ ⇥ to switch window by window.

Updated October 5, 2026

What macOS already offers

The closest built-in shortcut to Windows Alt-Tab is ⌘ ⇥ (Command-Tab). It cycles running apps and shows one icon per application. Releasing ⌘ brings that app’s most recent window forward.

⌘ and the grave accent (the key above Tab on a US keyboard) cycle windows of the frontmost app. Mission Control spreads windows on screen for you to click. Stage Manager groups windows and tucks the rest aside.

Where that falls short

⌘ ⇥ does not list windows. Three Safari windows are still one Safari. Grave accent only covers the frontmost app, on the current Space, and by default skips minimized windows. Mission Control is a mouse view, not a keyboard queue.

If you came from Windows, Alt-Tab muscle memory expects a row of windows. The Mac does not do that without an app.

How to do it with Tern

  1. Download Tern-x.y.z.dmg and drag the app into Applications. On first launch, macOS asks you to Open Anyway.
  2. Grant Accessibility when Tern asks. Without it, the shortcut cannot switch windows.
  3. Press ⌥ ⇥. Hold ⌥ and tap ⇥ to move forward. Release to focus the highlighted window.
  4. With the switcher open, type to filter by app name or window title. Search is free.
  5. If an app just gets in the way, ⌫ takes it off the list. How to hide apps.

The default shortcut is ⌥ ⇥ so it does not fight system ⌘ ⇥. Record a different one in Tern Settings. Do not record ⌘ ⇥: macOS reserves it.

Tern is a native window switcher (Swift), free, MIT licensed, for macOS 13 or later. There is a comparison with AltTab and others.
