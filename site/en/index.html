Features

The switcher your Mac is missing.

macOS ⌘⇥ shows one icon per app. Tern shows each window as a card, in the order you used them.

Windows, not apps

Every window is a card with a preview, in the order you used them. The previous one is always a tap away. Without Screen Recording, the card shows the icon and Tern still switches.

How to hide apps from the switcher →

Shortcuts

All from the keyboard.

⌥⇥ is the default; record another shortcut in Settings. Tern intercepts it so it doesn’t also fire in the frontmost app.

  • Open and move forward ⌥ ⇥
  • Move back ⇧ ⇥
  • Focus the window ⏎
  • Search type
  • Hide the app ⌫
  • Snooze for 1 hour ⇧ ⌫
  • Hide just the window ⌥ ⌫
  • Close the window ⌘ W
  • Minimize ⌘ M
  • Quit the app ⌘ Q
  • Close the switcher esc

Arrow keys move the selection too. While searching, ⌫ deletes text and esc clears the search: letting go of ⌥ confirms only when you haven’t typed.

tern://

Open it from anywhere.

In the Shortcuts app: open the switcher, hide an app, show it again, or change the mode. The same works from a tern:// link. Those links don’t close windows or quit apps.

  • tern://open opens the switcher
  • tern://hide?app=com.spotify.client&for=1h hides Spotify for an hour
  • tern://unhide?app=com.spotify.client shows it again
  • tern://mode?name=Work turns a mode on; without the name, turns it off

Frequently asked questions

Does the Mac have Alt-Tab? +

macOS does not have Alt-Tab. ⌘ ⇥ switches apps, not windows. To move between windows of the same app, the shortcut is ⌘ and the grave accent. Tern uses ⌥ ⇥ to switch window by window.

How is Tern different from ⌘⇥? +

macOS ⌘ ⇥ shows one icon per app. If Safari has three windows, ⌘⇥ still treats them as a single Safari. Tern shows each window as a card, in the order you used them. You can also type to search and hide apps from the switcher, which ⌘⇥ cannot do.

Is Tern free? +

Yes. Tern is free and open source under the MIT license. Type-to-search, exclusions, snooze, and modes are in the download. No account and no paid tier. If it's useful to you, you can support it on Ko-fi.

Why does Tern ask for Accessibility? +

macOS only lets an app read window titles and bring a window forward with Accessibility turned on. Tern does not read window contents. Without that permission, the shortcut cannot switch windows.

Why does macOS warn on first launch? +

Tern is not notarized by Apple yet. It is signed with its own certificate, and the source is on GitHub. On first launch, go to System Settings › Privacy & Security › Open Anyway. The help page has the steps.

Can I hide an app from the switcher? +

Yes. In the switcher, ⌫ hides the whole app and ⌥ ⌫ hides just that window. You can also hide by title, for an hour, or tie a mode to a macOS Focus.

How is Tern different from AltTab? +

Both are open-source window switchers for Mac. In AltTab, type-to-search is a Pro feature. In Tern, search is free. Tern is built around hiding apps and windows; AltTab is more mature, is notarized, and badges windows on other Spaces. There is a comparison.

Do I need Screen Recording? +

No. Screen Recording is optional and only used for card thumbnails. Without it, Tern still switches windows.

Switch windows without thinking.

Download Tern, grant Accessibility, and press ⌥ ⇥. If you already have it, the app installs 1.2 on its own.
