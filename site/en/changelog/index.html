Changelog

Newest first. If you already have Tern, the app installs the update itself, from Check for Updates in the menu.

1.2.0

October 4, 2026 Release
  • Search. With the switcher open, type to filter windows by app name and title.
  • Actions. ⌘ W closes the window, ⌘ M minimizes it, ⌘ Q quits the app.
  • Title rules hide windows like Picture in Picture, even when the name changes.
  • Snooze. ⇧ ⌫ hides an app for an hour. In Settings, until tomorrow too.
  • Modes hide an extra set of apps, and can turn on with a macOS Focus.
  • Automation. Shortcuts actions and tern:// links to open the switcher, hide an app, or change the mode.

1.1.4

October 2, 2026 Release
  • Asking for permissions opens one thing at a time, with no extra windows.
  • Screen Recording is no longer requested on its own: previews are optional, and the switcher works without them.
  • Pick your shortcut right in the welcome window.

1.1.3

October 2, 2026 Release
  • Tern now has a stable signature. After this update, later versions no longer ask for Accessibility again.
  • This update still asks one last time. If the switcher doesn’t open, remove Tern from System Settings › Privacy & Security › Accessibility and add it again.

1.1.2

October 2, 2026 Release
  • The highlight border of the selected card is no longer cut off at the sides of the switcher.

1.1.1

October 2, 2026 Release
  • Fixes 1.1.0, which quit right after launch. Automatic updates work from this version on.

1.1.0

October 2, 2026 Release
  • Welcome. On first launch, a window walks you through permissions.
  • Open at login, in the welcome window and in Settings.
  • Automatic updates. Tern tells you when a new version is out.
  • This build quit on launch. The fix shipped in 1.1.1.

1.0.1

October 2, 2026 Release
  • The Screen Recording permission button no longer makes a second copy of Tern. It just reveals the installed app in Finder.
  • The alerts ask you to quit and open Tern again, without a technical aside.

1.0.0

October 2, 2026 Release
  • First release. A menu bar window switcher, ordered by recency.
  • ⌫ hides an app and ⌥ ⌫ hides a single window.
  • A configurable shortcut, window previews, and an interface in English and Portuguese.
