Tern 1.2.0

  • Busca: com o seletor aberto, digite para filtrar as janelas. / Search: with the switcher open, type to filter windows.
  • Ações: ⌘W fecha a janela, ⌘M minimiza, ⌘Q encerra o app. / Actions: ⌘W closes the window, ⌘M minimizes, ⌘Q quits the app.
  • Regras por título para esconder janelas como Picture in Picture. / Title rules to hide windows like Picture in Picture.
  • Soneca: ⇧⌫ esconde um app por 1 hora. / Snooze: ⇧⌫ hides an app for an hour.
  • Modos que ligam junto com um Foco do macOS. / Modes that turn on with a macOS Focus.
  • Atalhos e links tern:// para automação. / Shortcuts actions and tern:// links for automation.
