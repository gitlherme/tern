Tern 1.1.0

  • Boas-vindas: uma tela guia as permissões no primeiro uso. / A welcome window walks you through permissions on first launch.
  • Abrir ao iniciar sessão nos Ajustes do Tern. / Open at login, right in Tern's Settings.
  • Atualizações automáticas: o Tern avisa quando sair uma versão nova. / Automatic updates: Tern tells you when a new version is out.

Depois de atualizar, se o seletor não abrir, remova o Tern em Ajustes do Sistema › Privacidade e Segurança › Acessibilidade e adicione de novo. / After updating, if the switcher doesn't open, remove Tern from System Settings › Privacy & Security › Accessibility and add it again.
