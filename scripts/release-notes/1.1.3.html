Tern 1.1.3

  • O Tern passa a ter uma assinatura fixa: depois desta atualização, as próximas versões não pedem mais a permissão de Acessibilidade de novo. / Tern now has a stable signature: after this update, future versions no longer ask for Accessibility again.

Esta atualização ainda pede uma última vez: se o seletor não abrir, remova o Tern em Ajustes do Sistema › Privacidade e Segurança › Acessibilidade e adicione de novo. / This update asks one last time: if the switcher doesn't open, remove Tern from System Settings › Privacy & Security › Accessibility and add it again.
